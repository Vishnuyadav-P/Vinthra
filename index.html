  • DOM-05

    CI/CD pipelines, Docker & Kubernetes container orchestration and cloud infrastructure.

How the program runs

  1. 01

    Pick your domain

    Choose from AI, ML, Data Science, Full-Stack or DevOps based on your interest and elective track.

  2. 02

    Get matched with a mentor

    A working engineer or domain specialist scopes the project with you and signs off on the architecture before a line of code is written.

  3. 03

    Build in guided sprints

    Weekly check-ins keep the build on schedule, with code review and unblockers along the way — not just a deadline at the end.

  4. 04

    Present & defend

    Leave with a rehearsed demo, a defensible viva walkthrough, and documentation your evaluator can actually follow.

What every project ships with

  • Project guidance from a mentor
  • A working GitHub repository
  • Full documentation
  • Presentation deck (PPT)
  • Live demo, ready for viva
Format

Small mentor-led batches · 6–8 week guided sprints · fully remote-friendly, with weekly milestones so nothing gets rebuilt the week before submission.
